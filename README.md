# Star Technology Calculator Data Exports

This repository hosts exported binary data files for use with the [Star Technology Calculator](https://github.com/alexperovich/star-technology).

These files are generated using the export pipeline described in the [Star Technology Calculator repository](https://github.com/alexperovich/star-technology).

## Important Notes

- **Binary Format**: The exported files are binary and cannot be easily diffed or version-controlled in the traditional sense.  
  New versions must be created starting from the commit where this README was added to ensure a clean history.
